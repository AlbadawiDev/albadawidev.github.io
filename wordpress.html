The paid assignment

First Cognition engaged Daniel through Upwork for one paid WordPress plugin customization, November 2025 to January 2026. The task adapted a blog and articles plugin to a client reference design.

The public lab below is a new portfolio exercise. It is not the client's original implementation, and its tests are not presented as historical tests from that assignment.

The public lab: Reference Cards

A shortcode renders published WordPress posts as responsive article cards. The scope stays small: category selection, a bounded card count, plain-text excerpts, accessible links and an empty state. It does not need a page builder, third-party service or API key.

PHP and WordPress

Shortcode registration, WordPress post queries, category filtering and escaped HTML output. Source and setup are included.

Functional QA

Real WordPress integration checks verify drafts, category filters, count bounds and unsafe text. The checklist also separates visual review from automated checks.

Verification

Reproduce the result

The WordPress lab workflow installs a disposable WordPress and MySQL environment, executes the plugin checks and retains the rendered HTML and test report. The run records the actual WordPress and PHP versions.

Download or inspect the lab from GitHub, follow its README, and run the same checks. A passing integration run confirms the tested fixtures. Mobile layout and keyboard behavior require the separate manual checklist.

Actual WordPress output

29 of 29 functional checks passed in the verified run on 12 October 2026: WordPress 7.1.3, PHP 8.3.35 and MySQL 8.4.11. The preview below contains the real shortcode output with fictional posts. It is a static snapshot, not an online WordPress installation.

Scope and ownership

This lab uses fictional articles and contains no customer account, institutional data or private design. It was prepared with coding assistance as a portfolio learning project. Daniel should run it and explain the decisions before representing them in an interview. It does not establish professional experience with Elementor, ACF, Shopify or production hosting.

Para un encargo: comparte la página, el cambio esperado y una referencia. Primero acordamos el alcance, el plazo, el respaldo y la remuneración. Después entrego el cambio y una nota de validación.
